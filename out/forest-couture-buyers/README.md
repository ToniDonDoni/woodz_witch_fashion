# Forest couture: procedural front row

An isolated proposal from main. Black background, narrow reflective catwalk, one row of seated animal-headed buyers (wolf, owl, fox, deer, raven, hare, moth and lynx) wearing tailored fashion, glasses, jewelry and holding phones or champagne. The original 33-frame walking woman is rendered in front. No forest or tree layer.

The audience is procedural Canvas 2D, not a photorealistic image generator. All geometry is drawn from deterministic vector primitives, gradients and tiny hair highlights. It is **editorial illustration**, not a photograph; this limitation must be considered in review.

`template.html` contains placeholders for `audience.js` and the original embedded walking atlas. `site/forest-couture-buyers/index.html` is the generated offline standalone page.

Manual visual review should compare with the supplied image and specifically check whether the animals are convincing as photographic editorial fashion buyers. If not, do not claim photorealism. The page is intentionally published as an experiment, not promoted into the accepted forest page.
