## Automated evidence

- Offline Chromium 149: no external HTTP requests or runtime errors.
- 1000 planned events: each block contains all eight families, no adjacent family repeats.
- Ten minutes of sampled rendering: at most one staged visitor, 68 cached forest drawings and 79 total active scene entries.
- Ten-hour seek and return: identical nonblank canvas pixels at the same seed/time.
- Pause, play, next guest, pace, reseeding and reduced-motion initial pause verified.
- Four viewport sizes captured; walker bounds and control-row bounds fit.
- 120 timed draws at portrait size: median 6.8 ms, p95 7.5 ms on this machine.
- 120 seconds of uninterrupted offline portrait playback: 120.10 simulated seconds, 7203 sampled frames, median RAF interval 16.7 ms, p95 17 ms. No errors or object growth.

The local headless GPU screenshot path initially produced empty capture surfaces. Repeated verification with software rendering (`--disable-gpu`) produced nonblank captures and exact pixel replay; the verification script explicitly rejects an undersized blank determinism screenshot. These figures measure desktop Chromium, not a physical phone. Phone file-opening support, sustained thermal performance and physical-device FPS remain unverified.

## Design limits

There are eight authored creature/action grammars with procedural combinations, not infinitely many handcrafted species. The line boil is 12 Hz; photographic sprite playback is 24 Hz. A fixed 24-second event slot provides a quiet gap after each 19–22-second performance. A fresh seed changes the cast order and details on each page load, while deterministic review can select a fixed seed.
